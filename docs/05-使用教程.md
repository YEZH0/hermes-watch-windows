# 使用教程：从下载到手表装好

> 这份教程面向**只想用、不想编**的人。
> 全程不装 Rust、不装 Visual Studio、不碰命令行、不需要 iLoader。
> 用 standalone 版的话，连 .NET 都不用装。
> 你需要的只有：一台 Windows、一根数据线、你自己的 Apple ID 密码。

如果你是要**从源码重建**或想搞懂原理，看 [00-从零开始.md](00-从零开始.md) 和 [01-原理.md](01-原理.md)。

---

## 0. 先花 60 秒确认你能不能做

三项硬条件，缺一项就不用往下看了：

| 条件 | 怎么查 |
| --- | --- |
| **64 位 Windows 10 / 11** | 设置 → 系统 → 关于 → 系统类型 |
| **iPhone + Apple Watch 已经配对** | 手表能收到 iPhone 的来电通知就算已配对 |
| **你记得自己的 Apple ID 密码** | 待会儿要登录，且要能收到 6 位验证码 |

还有**两件事软件替你做不了**，必须你亲手点：

1. **6 位两步验证码**——只推送到你的受信任设备，没有短信兜底也必须你本人
2. **手表上打开「开发者模式」**——在手表屏幕上点，点完要重启手表（第 3 步）

> 免费 Apple ID 就够，不用花钱。代价是**签出来的 App 只有 7 天有效期**（第 10 步讲续签）。

## 1. 下载三样东西

建一个干净目录，比如 `D:\Hermes`，三样都放进去。

| # | 下什么 | 从哪下 | 说明 |
| --- | --- | --- | --- |
| 1 | **HermesFixGui** | 本仓库 [Releases](https://github.com/YEZH0/hermes-watch-windows/releases) | 见下方「下哪个版本」 |
| 2 | **.NET 9 桌面运行时** | `dotnet.microsoft.com/download/dotnet/9.0` → *Desktop Runtime* → **x64** | 约 55 MB。**下了 standalone 就不用装** |
| 3 | **HermesEnabler.ipa** | `github.com/pookjw/HermesEnabler/releases` → 找 **1.5.1** → 下载 `HermesEnabler.ipa` | 约 923 KB |

### 下哪个版本

| 文件 | 大小 | 需要第 2 项吗 |
| --- | --- | --- |
| **HermesFixGui-standalone.exe** | 68 MB | **不需要**，双击就跑 |
| HermesFixGui.exe | 26 MB | 需要，先装好 .NET 9 |

不确定就下 **standalone**。它自带运行时，不用装东西，也不要管理员权限。

两个都带同一个签名引擎，功能完全一样。

### 核对一下有没有下错

`.NET 9` 别下成 *ASP.NET Core Runtime* 或 *SDK*，要的是 **Desktop Runtime**。
（只下 standalone 的话这条可以跳过。）

IPA 下来后可以核对指纹（可选，但建议）：

```powershell
Get-FileHash .\HermesEnabler.ipa -Algorithm SHA256
```

应当等于：

```
53a14e7e431f9c4e1b39aca76852f1a1207d551d489fc0d3a72791e0ad9b01bb
```

exe 的指纹：

```
standalone : 9d8476916acb745057b7a9636693ea117bd77135b43724345984f9add0c5eb49
runtime-dep: c38671d12516e0d8aadeb76b36b90907abb7d8215d6c23d9c283952b2709ba36
```

仓库根目录的 `SHA256SUMS.txt` 里还有引擎和脚本的哈希。

**指纹对不上就别用**——这个工具要拿你的 Apple ID 密码去登录，来路不明的 exe 不能碰。

### 1.1 EXE 和 IPA 是两个东西，版本号不用对齐

| | 是什么 | 谁在维护 |
| --- | --- | --- |
| **HermesFixGui.exe** | 签名工具。它**不包含**爱马仕表盘，只负责把 IPA 重签一遍再装进你的设备 | 本仓库 |
| **HermesEnabler.ipa** | 真正装到手表上的应用，爱马仕表盘在它里面 | 上游 [pookjw/HermesEnabler](https://github.com/pookjw/HermesEnabler) |

所以：

- **两个版本号不需要一致。** 工具 v1.2 既能签 1.5.1，也能签以后的新版本
- **工具更新**通常只改界面和流程，不改"签出来的东西"
- **换 IPA 版本**等于换了要装的应用，和工具版本无关

### 1.2 已验证的版本 vs 上游最新版

- **1.5.1 是实测过的**：真机从签名到装进手表完整跑通过一次
- **上游可能已经出了更新的版本**（查 [releases](https://github.com/pookjw/HermesEnabler/releases)）。新版本通常也能签，但**没有经过本项目的真机验证**
- 自检里显示「与已知 1.5.1 不一致」是**提醒不是阻止**——它照样会签，只是不保证结果

想稳就用 1.5.1。想尝鲜自己去上游下，出问题别怪工具。

## 2. 装 .NET 9 桌面运行时（只下 26 MB 版才需要）

下了 **standalone** 的话，**这一步直接跳过**，去第 3 步。

否则双击下载好的 `windowsdesktop-runtime-9.x.x-win-x64.exe`，一路下一步。

装完**不用重启**。验证方法：直接双击 `HermesFixGui.exe`，能出窗口就成了。

如果弹出类似「You must install .NET Desktop Runtime」的对话框，说明：
- 下成了 x86 版本 → 换成 x64
- 下成了 ASP.NET Core Runtime → 换成 Desktop Runtime

## 3. 打开手表开发者模式（最容易卡住的一步）

这一步不做，前面全白干，而且**报错很含糊**，可能一直卡在最后一步。

### 3.1 iPhone 上

1. 设置 → 隐私与安全性 → 拉到底 → **开发者模式**
2. 打开开关 → 提示要重启 → **重启 iPhone**
3. 重启后会弹窗问「要打开开发者模式吗」→ 点「打开」→ 输锁屏密码

> 如果找不到「开发者模式」这一项：先用数据线把 iPhone 连一次电脑（第 4 步），
> 让系统识别到设备，这个菜单通常就会出现。

### 3.2 手表上

1. 手表上：设置 → 隐私与安全性 → **开发者模式**
2. 打开 → 重启手表（长按侧边按钮 + 数码表冠）

### 3.3 判据

- iPhone：开发者模式开关显示为**已打开**
- Watch App（iPhone 上的「Watch」应用）→ 通用 → 里能看到与开发者相关的条目

不确定就打开软件的「环境自检」，这一项会如实标成 **「需人工」**——它判不了，也不假装通过。

---

## 4. 连线

1. 用**能传数据的线**把 iPhone 连到电脑（很多附赠线只能充电，换一根试）
2. iPhone 弹出「**要信任此电脑吗**」→ 点「信任」→ 输锁屏密码
3. **手表放上充电器**（安装阶段要求手表在充电且靠近 iPhone）
4. 确认手表和 iPhone 连的是**同一个 Wi-Fi**
5. 让 iPhone 保持**解锁、停在主屏**，整个过程中不要锁屏

### 判据

Windows「此电脑」里能看到你的 iPhone；软件自检里的「iPhone 连接服务」显示**通过**。

> 这一步的原理：软件不直接连手表，而是通过 iPhone 上的 `CompanionProxyService`
> （本机 27015 端口）中转，再由 iPhone 推给手表。所以 **iPhone 必须连着、必须信任**。

## 5. 打开软件，先看自检

双击 `HermesFixGui.exe`。

首次启动会做两件事：把内嵌的签名引擎释放到 `%LOCALAPPDATA%\HermesWatch\engine\`，然后跑一遍**环境自检**。

自检共 6 项：

| 项目 | 通过的样子 | 不通过怎么办 |
| --- | --- | --- |
| 运行环境 | 64 位 Windows | 换 64 位系统，没别的办法 |
| 签名引擎 | 显示 xx MB 与路径 | 杀毒软件误删了，加白名单后重开 |
| 签名文件 | HermesEnabler 1.5.1 · 指纹匹配 | 还没选 IPA，正常；选了但「与已知 1.5.1 不一致」也能签，只是不保证 |
| iPhone 连接服务 | 通过 | 回第 4 步：换线、重新信任、解锁手机 |
| Anisette 服务 | 通过 | 公共实例偶尔抽风，等几分钟重开软件 |
| 手表开发者模式 | **需人工** | 这一项软件判不了，自己回第 3 步确认 |

**「需人工」不是失败**，是它诚实地告诉你这一项得你自己看。

自检里出现「未通过」就别急着点开始，先按上表处理。

## 6. 选 IPA、填账号

1. 把 `HermesEnabler.ipa` **拖进窗口**，或者点「选择文件」
2. 填 Apple ID（完整邮箱，别只填前面的名字）
3. 填密码

> 密码只通过子进程的环境变量传给引擎，**不写磁盘、不进日志**。
> 日志里出现的账号和验证码都是 `••••••` 掩码。
> 但引擎本身要拿它去 Apple 服务器换 token——这一点绕不过去，请只在本机运行。

## 7. 开始，然后等 6 位码

点「**开始签名并安装**」。

跑到登录阶段时，界面里会出一条 **两步验证** 输入框。同时会有一个 6 位码的弹窗出现在你**某台** Apple 设备上。把 6 位数字填进去，回车。

> 验证码只在内存里回传给引擎，用完即弃，不落盘。

### 7.1 验证码到底发到哪了

**不一定是插着数据线的这台 iPhone。** Apple 会推送到这个 Apple ID 的**任一受信任设备**：

- 另一台 iPhone、iPad、Mac、Apple Watch
- 甚至可能是已经卖掉但还没从账号里移除的旧设备

所以第一件事是：**在所有 Apple 设备上找一遍**，包括抽屉里那台旧 iPhone。

### 7.2 三个按钮到底做什么

界面上的按钮会往引擎里写一条指令，引擎转成 Apple 的请求。**点了不等于一定送到。**

| 按钮 | 实际动作 | 该在什么时候用 |
| --- | --- | --- |
| **再推送** | 让 Apple 重新往受信任设备推一次 | 等了 30 秒以上没动静，或推送弹窗被误关了 |
| **短信** | 请求 Apple 改走短信通道 | 受信任设备不在身边 / 收不到推送 |
| **中止** | 结束本次登录 | 确实拿不到码，想重来 |

几个必须知道的事实：

- **点了「短信」不代表短信一定来。** Apple 可能拒绝降级到短信，也可能只给一个"其他验证方式"的入口。遇到这种情况只能回去找受信任设备。
- **验证码有效期很短**（几分钟）。收到后立刻填，别先干别的。
- **连续失败会被限流。** 反复点「再推送」很容易触发，这时候越点越糟，等十几分钟再试。

### 7.3 为什么别人的账号能用，我的就收不到

不同 Apple ID 的两步验证配置完全不同，这不是工具能改的：

| 你的账号情况 | 表现 | 能不能继续 |
| --- | --- | --- |
| 有多个受信任设备 | 码推到其中一台，容易找不到 | 能，挨个找 |
| 只有一台设备，且不在身边 | 只能等它回到身边 | 能，但得等 |
| 绑定的手机号已停用 | 短信收不到，推送也没设备 | 不能，先去 appleid.apple.com 改号码 |
| 账号近期有异常登录 | Apple 要求额外验证（改密码、回答安全问题） | 不能，先在浏览器里把账号恢复正常 |
| 新注册 / 刚改过密码的账号 | 验证更严，可能直接拒绝第三方登录 | 换一个常用账号试 |

### 7.4 判断问题出在哪一层

按这个顺序排除，别一上来就怀疑工具：

1. **浏览器能登录吗？** 打开 `appleid.apple.com`，用同一个账号密码登一次。
   - 浏览器都登不上 → 账号或密码问题，和这个工具无关
   - 浏览器要验证码但你收不到 → 受信任设备/手机号的问题，先去 Apple 那边修
2. **浏览器能登、软件收不到码？** 看软件日志里登录那几行，是不是卡在发码之前就报错了（比如网络、anisette）。
3. **软件里能看到输入框，但设备毫无反应？** 这才是「推送没送到」，用「再推送」或「短信」。
4. **填了码报错？** 码过期了（重新点「再推送」）或输错了（`0` 和 `O`、`1` 和 `l`）。

> 工具的边界很清楚：它只是替你在命令行里走 Apple 的登录流程。**账号侧的验证策略、设备是否可信、短信能不能发，都在 Apple 手里**，工具绕不过去，也不该绕过。

### 7.5「改发短信到」里那几个号码是什么

登录时如果引擎从 Apple 那边拿到了受信任号码列表，2FA 输入框下面会多一行「**改发短信到**」，每个按钮是一个号码的尾号，比如 `***78`。

- 点哪个，就走哪个号码的短信通道，等于替你回答 Apple 的「发到哪个号」。
- 只显示尾号，**完整号码不显示、不记录、不导出**。要确认是不是你的号，看尾号。
- 只列出引擎真的报上来的号码。没这一行，说明引擎这次没拿到列表（或者账号本来就没绑号码），不是软件坏了——直接用上面的「短信」或「再推送」。
- 号码尾号也可能对应你已经停用的旧号。发出去收不到，就换一个再试，别连续点。

### 7.6 把日志交出去之前

底部有「**导出日志**」。它存的是**屏幕上那份**，不是引擎的原始输出：

| 会被替换掉 | 替换成 |
| --- | --- |
| 完整手机号 | `***` + 后两位（原有的尾号掩码保留） |
| Apple ID 邮箱 | 首字母 + `***@域名` |
| 设备 UDID | 头 4 位 + `…` + 尾 4 位 |
| 路径里的 Windows 用户名 | `<user>` |
| 6 位验证码、密码 | 本来就不写进日志，只回显「已提交」 |

保留的是排错真正要用的东西：四个阶段的标记、错误码、失败原因、进度百分比、扫到的设备型号。

> 这是**尽力而为的脱敏，不是保密承诺**。格式能认出来的才挡得住；遇到没见过的输出格式可能漏。发出去之前自己扫一眼，别默认它是干净的。软件不会把日志上传到任何地方，导出只落在你选的本地路径。

## 8. 看懂四个进度块

界面上方四个块对应引擎的四个阶段。卡住时看它停在哪：

| 阶段 | 在干什么 | 卡在这里通常意味着 |
| --- | --- | --- |
| **登录** | Apple ID 认证 + 取 anisette 数据 | 密码错、验证码没回来、网络不通 |
| **准备** | 建证书、注册 App ID、开通 App Group、生成 Profile | 免费账号 3 张证书用完了；或账号被风控（`-80045` / `-45061`） |
| **签名** | 把 Profile 里的 entitlements 写进 iPhone 与 watch 两个二进制 | IPA 版本不对，或文件损坏 |
| **安装** | 先装 iPhone，再经 iPhone 推到手表 | **手表没开开发者模式**、手表没在充电、手表没连上 |

想中途放弃就点「停止」——它会连引擎子进程一起结束，不会留下半死不活的进程。

## 9. 怎么算成功

按顺序确认，四步全过才算真的成功：

1. iPhone 桌面上出现 **HermesEnabler** 图标
2. **手表上**也出现 HermesEnabler（在手表的应用列表里）
3. 手表上打开它，**不再报** *An App Group ID may be missing*
4. 手表 App → 表盘 → 能看到爱马仕表盘并可以选

### 第 3 步报错了怎么办

那说明 App Group 没写进去。先跑一次离线校验（需要电脑上有 Python 3）：

```powershell
python .\scripts\verify_appgroup.py <签名后的.ipa>
```

签名后的 IPA 在软件日志里会打印路径。期望看到 4 项全 OK：

```
[watch profile]  ... com.apple.security.application-groups = ['group.com.example.HermesEnabler.<TEAMID>']  -> OK
[iphone profile] ... -> OK
[iphone binary]  ... -> OK
[watch binary]   ... -> OK
```

- **4 项全 OK，手表还报错** → 签名没问题，是手表端没刷新生效：把手表上的 HermesEnabler 删掉，重跑一次
- **watch 那两项 NOT OK** → 引擎版本不对（用到了没打补丁的 isideload），换本仓库的 exe

## 10. 7 天后会失效，怎么续

免费账号签出来的 Profile **只有 7 天**。到期后手表上的 App 会打不开，这是正常的，不是你弄坏了。

续签只要 2 分钟：

1. 把 iPhone 连上电脑、解锁、信任
2. 手表放充电器
3. 打开软件 → 选同一个 IPA → 填账号 → 开始

**要注意的：**

- ⚠️ **不要**在 iLoader 里点「撤销证书 / 删除 App / 清除数据」——免费账号一共只有 **3 张**证书额度，用光就只能等
- 同一张证书会**复用**，续签不会重复消耗额度
- 换电脑、换 Apple ID 都要重新来一遍

## 11. 出问题怎么查

| 现象 | 最可能的原因 | 处理 |
| --- | --- | --- |
| 双击 exe 没反应 / 提示缺运行时 | 没装 .NET 9 **Desktop** Runtime | 换 standalone 版最省事；或用第 2 步装 Desktop（不是 ASP.NET） |
| 一直停在「登录」 | 密码错 / 验证码没填 / 网络不通 | 重开软件再来一次 |
| 报 `-80045` / `-45061` | Apple 账号被风控，anisette 与 client-info 来源不一致 | 与本工具无关，换个网络或等一段时间再试 |
| 卡在「准备」，提示证书数量超限 | 免费账号 3 张证书用完了 | 等已有的过期（约 7 天），或在 iLoader 里清理，**但清理本身也算消耗** |
| 卡在「安装」 | 手表没开开发者模式 / 没在充电 / 没连上 | 回第 3、4 步 |
| 手表报 *App Group ID may be missing* | 引擎没用打补丁的版本 | 用本仓库的 exe，别用别处下的 |
| 自检「iPhone 连接服务」不通过 | 线只能充电 / 没信任 / 手机锁屏 | 换线、拔了重插点信任、解锁 |
| 自检「Anisette 服务」不通过 | 公共实例不稳定 | 等几分钟重开 |

更多底层原因见 [03-踩坑记录.md](03-踩坑记录.md)。

## 12. 能不能把我的成果发给别人

**不能发签好的 IPA。** 里面嵌了你的证书和 Provisioning Profile，绑死了你的 Team ID 和你的设备 UDID：
别人的手机不在你的设备列表里，装不上；就算装上，7 天后也一起过期。

能分享的是**工具 + 未签名的 IPA**，让每个人用**自己的** Apple ID 重签一次：

> 把这个仓库地址发给对方 → 对方照这份教程从第 1 步做一遍。
> 各自消耗各自的 3 张额度，互不影响。
